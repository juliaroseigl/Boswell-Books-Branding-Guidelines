Prior to the rebrand, Boswell Books used a variety of typefaces, which were always a serif, such as Century or Times New Roman. However, they did not have a set hierarchy of typefaces. The rebrand will use set typefaces for a sepcific purpose, to create a more intentional, simplified branding system. Both typefaces used will be serifs, so as to continue in the branding tradition, and not create a completely new image for the viewer. The serifs will keep the classic charm that Boswell Books already has.


Header Typography

The typeface used for headers is Map Roman Variable Regular. Titles should be completely capitalized. This is a Roman serif font

A a, B b, C c, D d, E e, F f, G g, H h, I i, J j, K k, L l, M m, N n, O o, P p, Q q, R r, S s, T t, U u, V v, W w, X x, Y y, Z z


Body Copy Typography

The typeface for the body copy is Maxular Regular. This is a serif font that resembles an antique typewritter style. This contributes to the image of an antique bookstore
