There are 5 new icons created to go along with the rebrand, representing common functions to be used the store website. These icons include: wishlist, search, shopping cart, account login, and event calendar. The primary goal of the icon should be understandable, with a classic form, but still cohesive with the branding. These icons should be placed on a light green or light blue background so that both the beige and dark red stand out.
