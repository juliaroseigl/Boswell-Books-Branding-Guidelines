Rebrand Overview

This rebrand aims to emphasize a more welcoming persona. The primary values include honesty, integrity, reliability, quality, and inclusivity. The rebrand focuses on a new logo, type style, and color palette. The rebrand should stay true to Boswell Books, taking successful pieces of the current branding and shifting them only to better fit the new values.
